Equipo La Mera Paipa – Sistema SIAA

Descripción del proyecto:
El Sistema SIAA es un proyecto académico desarrollado para facilitar el registro, organización y consulta de reportes de inasistencias, actitudinales y académicos de los estudiantes. Su propósito es mantener toda la información en un solo lugar y facilitar el seguimiento de cada alumno.

Herramientas de desarrollo
GitHub: Utilizado para guardar y administrar el proyecto.
Django: Framework para desarrollar el sistema.
Python: Lenguaje de programación utilizado.
Visual Studio Code: Editor de código para trabajar en el proyecto.
