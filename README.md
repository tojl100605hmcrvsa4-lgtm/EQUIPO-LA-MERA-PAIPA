Equipo La Mera Paipa – Sistema SIAA
Descripción del proyecto

El Sistema SIAA es un proyecto académico desarrollado con el objetivo de facilitar el registro, organización y consulta de reportes de inasistencias, actividades y aspectos académicos de los estudiantes. Su propósito principal es mantener toda la información en un solo lugar, permitiendo que los datos sean más fáciles de administrar y consultar.

Además, busca mejorar el seguimiento del desempeño de cada alumno, agilizar la gestión de la información y reducir posibles errores al momento de registrar o consultar datos. Con este sistema se pretende ofrecer una herramienta práctica, organizada y sencilla de utilizar.

Herramientas de desarrollo
GitHub: Utilizado para guardar, compartir y administrar el proyecto, así como para facilitar la colaboración entre los integrantes del equipo.
Django: Framework utilizado para desarrollar la estructura y las funcionalidades del sistema.
Python: Lenguaje de programación utilizado para escribir la lógica y el funcionamiento de la aplicación.
Visual Studio Code: Editor de código utilizado para trabajar, modificar y revisar los archivos del proyecto.

💻 Colaboración y Retos del Equipo

Todos los integrantes colaboramos activamente en este proyecto, aportando ideas, conocimientos y habilidades para lograr desarrollar el Sistema SIAA. Durante el proceso de trabajo fue importante mantener una buena comunicación y organizarnos para repartir las actividades y cumplir con los objetivos establecidos.

Durante el desarrollo tuvimos varios errores y complicaciones técnicas, como conflictos al sincronizar cambios en GitHub, ajustes en las migraciones de Django y depuración de código. También fue necesario revisar y corregir algunos detalles para conseguir que las diferentes partes del sistema funcionaran correctamente.

Sin embargo, trabajando juntos, compartiendo soluciones y apoyándonos mutuamente, logramos resolver cada obstáculo para sacar el sistema adelante. Estas experiencias nos permitieron aprender más sobre el trabajo colaborativo, el uso de herramientas de desarrollo y la importancia de mantener una buena organización dentro de un equipo.

Aprendizajes y experiencia

La realización de este proyecto nos ayudó a reforzar nuestros conocimientos de Python, Django y GitHub, además de adquirir experiencia en el desarrollo de aplicaciones. También aprendimos que la comunicación, la paciencia y el compromiso de cada integrante son fundamentales para alcanzar una meta en común.

Como equipo, consideramos que este proyecto representa una oportunidad para poner en práctica lo aprendido durante nuestra formación académica y seguir mejorando nuestras habilidades como desarrolladores.
